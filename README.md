## 📖 Problem Summary

### ✅ Simple Array Sum
Calculated the sum of all elements in an array using iteration.

### ✅ Plus Minus
Calculated the ratio of positive, negative, and zero elements in an array with decimal precision.

### ✅ Birthday Cake Candles
Found the tallest candle and counted how many candles have the maximum height.

### ✅ CamelCase
Counted the total number of words in a CamelCase formatted string.

### ✅ Arrays - DS
Reversed the elements of an array efficiently.

### ✅ Left Rotation
Performed left rotation of an array by **k** positions.

### ✅ Java String Tokens
Extracted valid words from a string using regular expressions and string splitting.

### ✅ Java Anagrams
Checked whether two strings are anagrams by comparing their character frequencies.

### ✅ Array Manipulation

### ✅ Sherlock and Anagrams

## 📖 Problem Overview

### ✅ Maximum Element
Designed a stack that supports **push**, **pop**, and retrieving the **maximum element** in constant time by maintaining an auxiliary stack.

### ✅ Equal Stacks
Solved the problem of making three stacks equal in height by removing cylinders from the top using a greedy strategy.

### ✅ Simple Text Editor
Implemented a text editor capable of **append**, **delete**, **print**, and **undo** operations by storing previous states in a stack.

### ✅ Balanced Brackets
Checked whether a bracket sequence is balanced by using a stack to correctly match opening and closing brackets.

### ✅ Queue using Two Stacks
Built a queue using two stacks while preserving FIFO behavior for enqueue, dequeue, and front operations.

### ✅ Truck Tour
Determined the correct petrol pump index from which the truck can complete the circular route using a greedy approach.
